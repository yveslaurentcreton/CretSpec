## The problem

A project is rarely one repository, and every coding agent wants its own instruction files. You clone the repositories by hand, copy your rules into each one, and watch the copies drift between projects and machines.

## What you can do with it

- **Keep a project together.** All its repositories sit in one folder, each with its own Git history. [Combine repositories](/CretSpec/guides/workspaces/).
- **Reuse your rules and skills.** Write them once, use them in every project and improve them while you work. [Work with guidelines](/CretSpec/guides/guidelines/).
- **Combine guidelines.** Add a customer's rules next to your own and decide which wins. [Reference guidelines](/CretSpec/guides/workspaces/#reference-guidelines-and-other-projects).
- **Build on other projects.** Reference a project that also uses CretSpec and get its context. [Reference projects](/CretSpec/guides/workspaces/#reference-guidelines-and-other-projects).

CretSpec is one native executable for Windows, macOS and Linux. It needs no server, account or registry: your repositories stay plain Git, and the generated files stay local. [Install it](/CretSpec/start/install/).
