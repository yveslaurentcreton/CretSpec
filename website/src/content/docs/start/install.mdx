## Check your installation

Open a new terminal and check that both commands are available:

```sh
cspec --version
git --version
```

If `cspec` is missing or reports an unexpected version, check your PATH. Use `Get-Command cspec -All` in PowerShell or `type -a cspec` on macOS/Linux to find conflicting installations.

Then [clone your first project](/CretSpec/start/quickstart/).

## Build from source

Install [Git](https://git-scm.com/install/) and [Rust](https://rustup.rs/), including your platform's Rust build prerequisites:

```sh
git clone https://github.com/yveslaurentcreton/CretSpec.git
cd CretSpec
cargo install --path . --locked
cspec --version
```

These commands also work in PowerShell. The checkout pins Rust 1.97.1 in `rust-toolchain.toml`. If you already have a native source checkout, run `cargo install --path . --locked` there.

Cargo installs `cspec` into its binary directory: normally `~/.cargo/bin` on macOS/Linux or `%USERPROFILE%\.cargo\bin` on Windows. Add it to your PATH if necessary and reopen your terminal.

To update a Cargo installation, select the source revision you want and run the same install command again. To remove it:

```sh
cargo uninstall cretspec
```

## Release archives

Install manually from [GitHub Releases](https://github.com/yveslaurentcreton/CretSpec/releases/latest). Download your platform archive and `SHA256SUMS` from the same release. Prebuilt binaries need Git and the listed OS dependencies, but no Rust toolchain.

| Platform | Archive target | Baseline |
| --- | --- | --- |
| Windows x64 | `x86_64-pc-windows-msvc` | Windows 10/11; built and tested on Server 2022 |
| Linux x64 | `x86_64-unknown-linux-gnu` | glibc 2.35 or newer; Ubuntu 22.04 build |
| macOS Intel | `x86_64-apple-darwin` | CI on macOS 15 |
| macOS Apple silicon | `aarch64-apple-darwin` | CI on macOS 14 |

Linux needs the usual glibc and GCC runtime libraries. Alpine/musl and Linux/Windows ARM builds are outside this release matrix. macOS binaries are not notarized; respect your organization's application policy.

<details>
<summary>Verify, extract and add to PATH</summary>

On Windows, run `Get-FileHash <archive.zip> -Algorithm SHA256` in PowerShell and compare the complete hash with its entry in `SHA256SUMS`. Extract the archive and place `cspec.exe` in a directory on your user PATH.

On Linux, use `sha256sum <archive.tar.gz>`; on macOS, use `shasum -a 256 <archive.tar.gz>`. Compare the complete hash with the matching entry in `SHA256SUMS`. After extracting the archive, open a terminal in the extracted directory and run:

```sh
mkdir -p "$HOME/.local/bin"
install -m 755 cspec "$HOME/.local/bin/cspec"
```

Add `~/.local/bin` to your shell PATH if needed. Open a new terminal and run `cspec --version`.

To update, repeat the verified extraction with the new release. To uninstall, remove the executable you placed on PATH. Your project repositories remain independent.

</details>
